Boundary\n\nMetrics define what must be observable. Actual production telemetry deployment is outside this subarea.\n\n## SLO Boundary\n\nExact production SLO/SLA targets are intentionally deferred to Area 32.\n\n## Control Authority\n\nMetrics observe deterministic CDC, checkpoint, DQ, reconciliation, schema, metadata, orchestration, and recovery controls. Metrics do not override those controls.\n\n## AWS Boundary\n\nAWS monitoring implementation is a future deployment concern. AWS execution is not claimed by Area 31-B.\n
