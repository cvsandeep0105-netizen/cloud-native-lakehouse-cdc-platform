CDC Engineering

The Olist dataset is static historical data and does not provide a live production CDC stream. Generated changes derived from the historical source are therefore explicitly treated as CDC simulation/replay.

Separately, genuine PostgreSQL logical decoding was validated locally through pgoutput. The validation covered controlled INSERT, UPDATE and DELETE events, source-value verification, ordering and LSN progression.

CDC correctness controls include deterministic identities, deduplication, idempotency, checkpointing, replay, late-event handling and backfill boundaries.

Lakehouse Engineering

The layered platform follows the engineering flow:

Raw → Bronze → Iceberg → Silver → Gold

Local Iceberg validation covered all 9 datasets, including row-count reconciliation, column reconciliation and snapshot presence.

AWS boundary: the deployed AWS environment provides S3, KMS, Glue Catalog, Athena and related infrastructure. This report does not claim AWS-native Iceberg tables were deployed.

Metadata, Lineage & Governance

The platform maintains dataset metadata, column definitions and lineage stages to make data movement explainable. Governance controls cover contracts, ownership boundaries, data handling expectations, security controls and compliance-readiness documentation.

AI Engineering Boundary

AI-assisted data engineering is deliberately bounded. Deterministic data quality, reconciliation, security and governance controls remain authoritative. Autonomous production mutation is disabled and human review remains part of the control boundary.

Technology Decisions & Trade-offs

DecisionEngineering rationale
PostgreSQLRealistic operational relational source and genuine local logical CDC validation.
S3Durable object-storage foundation for the cloud data lake.
ParquetColumnar analytical storage with broad processing compatibility.
IcebergTable-format capabilities for schema, snapshot and incremental lakehouse engineering.
SparkDistributed processing model suitable for scalable data engineering.
TerraformDeclarative, reviewable and reproducible infrastructure definition.
AWS DMSEvaluated as a production CDC option but not falsely represented as deployed.

Production Boundary & Limitations

  • Olist is static historical data.
  • CDC simulation/replay is distinguished from genuine local PostgreSQL logical CDC.
  • AWS-native Iceberg tables are not claimed as deployed.
  • AWS DMS, Step Functions, EventBridge and Secrets Manager are evaluated candidates rather than deployed services.
  • Performance benchmarks are local engineering evidence, not AWS contractual SLAs.
  • Cost figures are engineering estimates/scenarios unless explicitly backed by observed billing evidence.
