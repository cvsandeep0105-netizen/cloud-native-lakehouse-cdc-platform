# Project 02 — Target Role & Capability Alignment

## 1. Primary Professional Identity

Primary identity: Data Engineer.

Project 02 strengthens the cloud data platform dimension of the portfolio, with emphasis on AWS, lakehouse architecture, CDC, incremental processing, data quality, governance, reliability, security, observability, infrastructure as code, CI/CD, performance, and cost engineering.

AI is treated as an engineering capability within the platform rather than the primary professional identity.

## 2. Target Roles

- Senior Data Engineer
- Lead Data Engineer
- Cloud Data Engineer
- AWS Data Engineer
- Data Platform Engineer
- Lakehouse / Data Infrastructure Engineer

## 3. Core Capabilities Demonstrated

- Cloud-native data platform architecture
- AWS data engineering
- Data lake and lakehouse architecture
- Apache Iceberg
- CDC and incremental data processing
- Batch and event-oriented data ingestion
- SQL and Python engineering
- Spark / PySpark distributed processing
- Data modeling and layered data architecture
- Data quality and reconciliation
- Metadata, catalog, lineage, and governance
- Pipeline orchestration and reliability
- IAM, encryption, secrets management, and security
- Observability and operational ownership
- Infrastructure as Code
- CI/CD and software supply-chain controls
- Performance and scalability engineering
- AWS cost engineering

## 4. Senior-Level Engineering Expectations

The project must demonstrate engineering judgment rather than simply demonstrate familiarity with individual AWS services.

Key expectations include:

- Clear architectural decisions and documented trade-offs.
- Explicit separation between local implementation and AWS-verified implementation.
- Reproducible pipelines and safe reruns.
- Deterministic correctness and reconciliation controls.
- Failure handling and recovery procedures.
- Security designed into the platform rather than added afterward.
- Quantitative evidence for important engineering claims.
- Operational documentation and runbooks.
- Testing at critical pipeline boundaries.
- Production-oriented thinking around scale, reliability, observability, and cost.

## 5. Portfolio Positioning

Project 01 demonstrates real-time streaming, large-scale telemetry processing, AI-enabled anomaly detection, APIs, and production-oriented platform engineering.

Project 02 demonstrates cloud-native lakehouse architecture, AWS data platforms, CDC, incremental processing, governance, reliability, security, and cloud economics.

Project 03 will later demonstrate modern data warehousing, analytics engineering, semantic/business modeling, and BI-ready consumption.

Together, the three projects form a coherent Data Engineer portfolio covering streaming, cloud lakehouse/data platforms, and analytics engineering.

## 6. Success Standard

Project 02 is successful only when the completed implementation provides credible evidence that the engineer can design, build, test, operate, secure, optimize, document, and explain a production-oriented cloud data platform.
