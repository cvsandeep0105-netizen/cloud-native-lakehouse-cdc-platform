# Data Classification & Governance Security

## Classification
- Restricted: credentials, private keys, authentication material, security configuration.
- Confidential: controlled operational and transactional information.
- Internal: engineering metadata and operational evidence.
- Derived analytical: approved Gold data products.
- Public: information explicitly approved for public release.

## Access Principle
Access permissions must correspond to the classification and business purpose of the data.

## Retention
Retention and deletion must follow documented governance requirements.

## Evidence
Evidence artifacts must contain validation results without exposing restricted data.

## AI Boundary
AI-assisted analysis must respect existing classification and authorization controls.
AI cannot downgrade classification or authorize access.
