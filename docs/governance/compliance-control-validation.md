# Compliance Control Validation

## Controlled Controls
- Access authorization exists.
- Secrets protection exists.
- Encryption strategy exists.
- Data quality controls exist.
- Reconciliation controls exist.
- Metadata and lineage exist.
- Retention governance exists.
- Audit evidence is attributable.
- Security incidents have operational handling.
- Governance decisions remain human controlled.

## Blocking Principle

Governance-control failures become blocking conditions when they affect security, privacy, data integrity, or applicable compliance obligations.
