# Data Governance Model

## Governance Roles
- Data Owner: accountable for business meaning and permitted use.
- Data Steward: maintains definitions, metadata, and quality expectations.
- Data Engineer: implements controlled data processing.
- Security Owner: governs access and security requirements.
- Platform Operator: manages operational execution.
- Auditor: reviews evidence and control effectiveness.

## Governance Artifacts
- Dataset contracts
- Column definitions
- Key and relationship definitions
- Data quality rules
- Reconciliation controls
- Metadata registry
- Lineage registry
- Access policies
- Retention policies
- Incident records
- Compliance evidence

## Human Accountability

Governance decisions require human accountability. AI can assist analysis but cannot authorize governance policy changes.
