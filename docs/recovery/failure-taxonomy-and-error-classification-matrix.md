ISOLATE_AND_INVESTIGATE | FALSE | Human review |\n\n## Classification Principles\n\n- Classify the failure at the narrowest responsible component.\n- Use observed evidence before selecting recovery action.\n- Never advance an authoritative checkpoint after an unsuccessful processing attempt.\n- Retry only failures classified as retryable.\n- Use replay or backfill only within deterministic processing boundaries.\n- Block downstream stages when an upstream blocking failure remains unresolved.\n- Require human review for schema, reconciliation, integrity, and unresolved failures.\n\n## Control Boundary\n\nDeterministic CDC ordering, deduplication, checkpoint, DQ, reconciliation, schema, metadata, and lineage controls remain authoritative.\n\n## AWS Boundary\n\nAWS-native failure handling may be implemented later. AWS execution is not claimed by this Area.\n
